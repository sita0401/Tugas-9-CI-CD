Tentang Halaman

Halaman ini adalah landing page yang di-deploy otomatis menggunakan GitHub Actions ke GitHub Pages. Setiap kali kode di-push ke repositori, proses build dan deployment berjalan sendiri tanpa deploy manual.

  • CI (Continuous Integration): kode otomatis di-checkout dan di-build setiap ada perubahan.
  • CD (Continuous Deployment): hasil build otomatis dipublikasikan ke server (GitHub Pages).
